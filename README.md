# Emerald Swarm

9:16 세로 화면 기준으로 만든 갤러그 스타일 터치 슈팅 게임. 의존성 없는 단일 HTML 파일이며,
`index.html`을 브라우저에서 열면 바로 실행된다.

## 조작

- **모바일** — 화면 아무 곳이나 끌면 기체가 손가락을 따라 움직인다 (손가락과의 거리를 유지하므로 기체가 손에 가려지지 않는다)
- **데스크톱** — 방향키 또는 WASD
- 빔은 자동으로 발사된다

## 규칙

| 대상 | 피격 횟수 | 점수 | 행동 |
| --- | --- | --- | --- |
| 일반 · 돌진형 | 3 | 20 | 일자로 하강, 충돌 시 피해 |
| 일반 · 사격형 | 3 | 20 | 일자로 하강, 3초마다 조준 빔 |
| 강적 · 추격형 | 8 | 100 | 플레이어를 따라오며 하강 |
| 강적 · 산탄형 | 8 | 100 | 일자로 하강, 1.5초마다 5방향 산탄 |
| 보스 · 스웜 마더 | 50 | 1000 | 1초마다 산탄 / 큰 산탄 / 빔 / 속사 빔 중 랜덤 |

- 플레이어 체력 3, 피격 시 1.5초 무적
- 발사 간격 0.5초 (RAPID 획득 시 0.22초)
- 웨이브 1~5를 클리어하면 보스가 등장하고, 격파 시 CLEAR

## 파워업

적 격파 시 드롭 (일반 12%, 강적 60%). 지속 시간 8초.

- **W** SPREAD — 빔이 2줄로, 중첩 획득 시 3줄로 퍼진다
- **R** RAPID — 연사 속도 상승
- **+** REPAIR — 체력 1 회복

## 구조

`index.html` 한 파일에 전부 들어 있다. 450×800 논리 좌표계를 쓰고 캔버스 변환으로 화면에
맞춰 스케일하므로 기기 해상도와 무관하게 동일한 난이도로 동작한다. 게임 루프는 델타 타임
기반이라 프레임 레이트가 흔들려도 속도가 변하지 않는다. HUD와 오버레이는 DOM,
플레이필드는 Canvas 2D로 그린다.

`prefers-reduced-motion`을 존중해 화면 흔들림과 파티클 수를 줄인다.
