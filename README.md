# Emerald Swarm

4:3 화면 기준 데스크톱 슈팅 게임. 경험치로 레벨업할 때마다 능력 카드 3장 중 1장을 골라
빌드를 쌓고, 끝까지 키운 능력 둘을 합쳐 전설 능력으로 진화시킨다.
의존성 없는 단일 HTML 파일이며 `index.html`을 브라우저에서 열면 바로 실행된다.

## 조작

| | |
| --- | --- |
| 이동 | 마우스를 따라 기체가 추종 · 방향키/WASD |
| 필살기 | 오른쪽 하단 버튼 · `SPACE` |
| 카드 선택 | 클릭 · `1` `2` `3` |
| 사격 | 자동 |

터치 기기에서는 화면을 끌어 이동한다 (손가락과의 거리를 유지해 기체가 가려지지 않는다).

## 성장 시스템

### 경험치와 레벨업

적을 처치하면 경험치 젬이 떨어지고, 일정 거리 안에서 기체로 빨려온다.
필요 경험치는 `10 + 7L + 1.2·L^1.75` — 초반은 빠르고 후반으로 갈수록 느려진다.

레벨업하면 **전투가 완전히 정지**하고 (적·탄환·플레이어·타이머 전부) 화면 중앙에 능력 카드
3장이 뜬다. 1장을 고르면 즉시 적용되고 전투가 재개된다. 레벨업이 여러 번 밀리면 카드 선택이
연속으로 이어진다.

### 능력 카드

능력은 `ABILITIES` 배열 하나로 관리된다. 항목 하나를 추가하면 카드 UI, 등장 확률, 능력치
계산에 자동으로 반영된다.

```js
{ id, name, icon, rarity, max:5, tags:[], vals:[...], eff:(level, vals) => '설명' }
```

능력치는 명령형으로 누적하지 않고 `recomputeStats()`가 **보유 레벨에서 매번 파생 계산**한다.
같은 카드를 다시 골라도 중복 적용되지 않고, 레벨만 올리면 결과가 항상 일관된다.

#### 능력 20종

| 계열 | 능력 |
| --- | --- |
| 공격 강화 | 화력 증폭 · 속사 장치 · 가속 탄자 · 급소 관통 |
| 탄환 변화 | 다중 탄환 · 관통탄 · 대구경 탄 · 벽 반사 · 유도 탄자 · 분열탄 |
| 속성 | 화염탄(화상 지속 피해) · 얼음탄(둔화·빙결) · 전기탄(연쇄 감전) · 독탄(중첩 지속 피해) |
| 소환 | 미니 드론 · 회전 칼날 |
| 특수 공격 | 메테오 · 폭발탄 |
| 유틸리티 | 강화 장갑 · 자기장 코일 |

전부 5레벨까지 성장하며, **Lv.5에서는 수치 상승이 아니라 동작이 바뀐다.**
예: 화염탄 MAX는 화염 장판을 남기고, 관통탄 MAX는 무한 관통에 관통마다 피해가 10%씩 붙고,
폭발탄 MAX는 확률이 아니라 모든 명중이 폭발한다.

### 진화

재료 능력 둘이 모두 MAX가 되면 **다음 레벨업 카드에 진화 카드가 등장**한다 (전투를 강제로
끊지 않는다). 진화해도 재료 능력은 사라지지 않는다.

| 진화 | 재료 | 효과 |
| --- | --- | --- |
| 🔥🌀 화염 폭풍 | 화염탄 + 다중 탄환 | 모든 탄환이 화상 부여 · 2.5초마다 화염 노바 |
| ⚡🌩️ 연쇄 번개 폭격 | 전기탄 + 분열탄 | 연쇄 대상 +3 · 3초마다 적 5체에 낙뢰 |
| 🤖 전투 드론 시스템 | 미니 드론 + 속사 장치 | 드론 4대 · 연사 2배 · 전원 유도 미사일 |
| 💠 절대영도 | 얼음탄 + 회전 칼날 | 칼날이 빙결 부여 · 빙결 적 파괴 시 냉기 폭발 |
| ☣️ 역병 폭발 | 독탄 + 폭발탄 | 중독 적 처치 시 맹독 구름 확산 |
| 🔫 레일건 | 관통탄 + 가속 탄자 | 2.2초마다 화면을 관통하는 레일 사격 |

진화 조건은 데이터로 관리되므로 `EVOLUTIONS` 배열에 항목만 추가하면 된다.

```js
{ id:'fire_storm', name:'화염 폭풍', icon:'🔥🌀',
  requires:{ fireB:5, multishot:5 }, eff:()=>'...' }
```

### 카드 등장 확률

완전 무작위가 아니라 현재 빌드를 반영한다.

- 희귀도별 기본 가중치 (COMMON 100 / RARE 50 / EPIC 20 / LEGENDARY 6)
- 이미 보유한 능력 ×1.35
- 태그가 겹치는 능력을 가질수록 최대 ×1.8 (화염 빌드면 화염·광역 계열이 더 자주)
- 진화 재료 중 하나를 Lv.3 이상 키웠으면 나머지 재료 ×1.6
- MAX에 도달한 능력은 풀에서 제외되고, 진화 가능하면 진화 카드가 한 자리를 확보한다
- 모든 능력이 MAX면 안전망으로 **완전 정비**(체력 전회복 + 필살기 완충 + 500점) 카드가 나온다

## 생존 시스템

체력과 라이프가 분리되어 있다.

- **체력바** — 화면 왼쪽 세로 바. **최대 체력이 늘어도 바의 길이는 고정**되고 눈금만 촘촘해진다
- 기본 최대 체력 3 → **3번 맞으면 라이프 1 소모**. 강화 장갑으로 최대 9까지
- **라이프 2** — 소진 시 체력을 채워 부활 (2.4초 무적). 획득한 능력 카드는 유지된다
- 라이프 2개를 모두 소진하면 게임오버 화면 + 빌드 요약 + 재도전 버튼

## 필살기

적에게 명중할 때마다 오른쪽 하단 버튼에 물이 차오른다 (1회당 2.2%). 완충 시 `FIRE`로 바뀌며,
발사하면 **초당 26 피해의 굵은 레이저를 3초간** 유지한다. 지속 중에는 무적이고 레이저에 닿는
적탄이 소멸한다. 피해는 소수점 누산기로 계산해 프레임률과 무관하게 일정하다.

## 적

| 계층 | 유형 | 행동 |
| --- | --- | --- |
| **일반** | 스카웃 | 일직선 하강, 접촉 피해 |
| | 슈터 | 일직선 하강 + 아래로 직선 빔 |
| | 트레일러 | 플레이어의 움직임을 **0.5초 지연**으로 추종 |
| **덴져** | 램 | 하강 → 제자리 정지·조준(점선 표시) → **빔과 같은 속도로 돌진** |
| | 랜서 | 일직선 하강 + 플레이어 조준 빔 |
| | 헐크 | 그냥 내려오지만 단단함 |
| **크리쳐** | 스토커 | **빔 속도의 70%**로 플레이어를 향해 하강 |
| | 스프레이 | 7방향 산탄 |
| **보스** | | 산탄 / 큰 산탄 / 조준 빔 / 속사 빔 + **차지 공격** |

크리쳐는 **웨이브당 최대 3마리**만 동시에 존재하고, 진행도 15웨이브 이전에는 등장하지 않는다.
초과분은 자리가 날 때까지 스폰이 지연된다.

보스는 **체력이 절반 이하로 떨어지면 격노**해 체력바가 마젠타로 바뀌고, 8초마다 1.2초간 충전한
뒤 34발씩 5연발 — 화면을 뒤덮는 차지 공격을 퍼붓는다 (실측 동시 적탄 179발).

강적 이상은 머리 위에 체력바가, 상태이상은 발밑에 색 표식(🔥❄️☠️)이 표시된다.

## 레벨 디자인

**5 스테이지 × 50 웨이브 = 250 웨이브.** 10웨이브마다 보스, 50웨이브는 스테이지 최종 보스.

| 스테이지 | 이름 | 색 |
| --- | --- | --- |
| 1 | EMERALD BELT | 🟢 `#4ade5f` |
| 2 | AZURE DRIFT | 🩵 `#3ce0c0` |
| 3 | VIOLET REACH | 🟣 `#a77bff` |
| 4 | EMBER SPAN | 🟠 `#ffa53c` |
| 5 | CRIMSON VOID | 🔴 `#ff5b5b` |

난이도는 `(스테이지-1) + 웨이브/50` 으로 연속 계산된다 — 스테이지 경계에서 튀지 않고
웨이브마다 조금씩 올라간다. 이 값이 적 체력(+82%/단계), 이동 속도(+9%), 사격 간격(−8%),
탄속(+9%), 획득 점수(+50%), 경험치(+35%)에 동시에 반영된다.

적 유형은 진행도에 따라 순차 해금된다 — 스카웃(1) → 슈터(3) → 헐크(5) → 트레일러(8) →
랜서(12) → 크리쳐(15) → 램(20).

배경 성운, 적, 보스, 보스 체력바가 모두 스테이지 색을 따라가 50웨이브 단위로 화면 전체
팔레트가 바뀐다.

## 스킨

보스를 처음 격파하면 **VANGUARD** 스킨이 해금되어 즉시 장착된다. `localStorage`에 저장되어
다음 판부터 처음부터 적용된다.

## 코드 구조

`index.html` 한 파일이지만 역할별로 구획이 나뉘어 있다.

| 구획 | 역할 |
| --- | --- |
| `CONFIG` | 상수, 스테이지 정의 |
| `ENEMY DATA` | 적 8종 데이터 테이블 |
| `ABILITY DATA` | 능력 20종 + 진화 6종 + 희귀도 |
| `PLAYER STATS` | `recomputeStats()` — 능력 레벨 → 파생 능력치 |
| `ABILITY MANAGER` | `grant` `availableEvolutions` `synergyWeight` `drawCards` |
| `LEVEL SYSTEM` | `expNeed` `gainExp` `openPicker` `choose` |
| `CARD UI` | `renderCards` |
| `HUD SYNC` | `syncHud` `syncExp` `syncHp` `syncKit` `syncUlt` `banner` `toast` |
| `WAVES` / `SPAWNING` | `buildWave` `setWave` `nextWave` `spawnFoe` `spawnBoss` |
| `COMBAT HELPERS` | `damage` `killFoe` `explode` `chainZap` `applyElements` |
| `UPDATE` / `RENDER` / `INPUT` / `FLOW` | 시뮬레이션과 그리기 |

800×600 논리 좌표계를 쓰고 캔버스 변환으로 화면에 맞춰 스케일하므로 해상도와 무관하게 동일한
난이도로 동작한다. 게임 루프는 델타 타임 기반이고, 레벨업 중에는 `render(0)`으로 애니메이션
시간까지 정지시킨다. HUD·카드·오버레이는 DOM, 플레이필드는 Canvas 2D로 그린다.

`prefers-reduced-motion`을 존중해 화면 흔들림, 파티클 수, 게이지 애니메이션을 줄인다.

### 테스트 훅

`window.__ES__`로 상태 스냅샷과 디버그 조작을 노출한다 (`snap` `give` `addExp` `spawn`
`setStage` `damageBoss` `hurt` `killAll` `choose`). 자동화 테스트용이며 프로덕션에서는
제거해도 게임 동작에 영향이 없다.
